공유해서 저장

다른 앱에서 링크를 공유하거나 주소를 붙여넣고 제목과 메모를 남깁니다.

단서로 검색

제목·메모·분류와 직접 첨부한 이미지의 OCR 텍스트를 이용합니다. OCR은 기기에서 실행하지만 첨부 이미지와 인식 결과는 서버로 전송됩니다.

원문 다시 열기

찾은 링크를 원래 앱이나 브라우저로 엽니다. 원문 사이트의 로그인 요구나 삭제된 게시물을 해결하지는 않습니다.

현재 지원 범위

링크 보관, 규칙 기반 분류, 검색, 항목당 이미지 한 장 첨부와 계정 탈퇴를 지원합니다. SNS 좋아요 자동 수집·전체 영상 분석·생성형 AI 분석은 제공하지 않습니다. 오프라인 대기와 서버 저장 완료는 구분됩니다.
