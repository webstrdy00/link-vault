계정과 보관 자료 삭제

LinkFileBox 계정 탈퇴와 보관 자료 삭제 방법을 안내합니다.

LinkFileBox 운영자가 제공하는 앱의 계정 탈퇴 안내입니다. 탈퇴는 되돌릴 수 없습니다. Google 계정 자체를 삭제하는 절차는 아닙니다.

1. 앱에서 탈퇴하기

  1. LinkFileBox에 로그인하고 하단 설정에서 계정 화면을 엽니다.
  2. 계정과 서버 자료 삭제를 선택합니다.
  3. 삭제 안내를 읽고 Google 재인증을 진행합니다. 삭제하려는 현재 계정을 선택해 본인임을 확인합니다.
  4. 삭제 요청 결과를 확인합니다. 오류나 대기 상태가 표시되면 완료로 판단하지 말고 앱의 안내에 따라 진행 상태를 확인합니다.

로그아웃이나 앱 제거만으로 서버 계정이 삭제되지는 않습니다. 로그아웃은 서버 계정·보관함을 유지한 채 이 기기의 계정 자료를 정리하는 동작입니다.

2. 삭제 범위와 소요 시간

탈퇴 처리 대상은 LinkFileBox의 인증 계정·프로필·회원 승인 정보·보관 항목·첨부 이미지와 인식 결과 등 계정에 연결된 서비스 자료입니다. 기기 자료 정리에 실패했다는 경고가 나오면 서버 삭제와 별개로 기기 정리를 확인해야 합니다.

운영 자료 정리는 72시간 이내를 목표로 하지만 완료 시간을 보장하지 않습니다. 삭제 작업·감사 기록은 활성 계정 자료와 구분되며 최종 보관 기간은 개인정보 안내 검토 과정에서 확정합니다.

운영 백업은 최대 30일 순환을 목표로 하며 즉시 모든 사본이 사라진다는 뜻은 아닙니다. 로컬 백업의 최근 7개 보관은 일수 제한과 다릅니다. 복원 시 삭제 요청을 다시 적용하는 절차가 필요합니다. 자세한 제한은 개인정보 안내 검토본을 확인하세요.

3. 앱에 접근할 수 없을 때

support@linkfilebox.com으로 삭제 요청을 보내주세요. 가능하면 가입한 Google 이메일에서 요청하고 앱 접근이 어려운 상황을 짧게 설명하세요.

메일 발송만으로 계정을 자동 삭제하지 않습니다. 운영자가 계정 소유를 확인한 후 처리해야 합니다. 비밀번호·인증 코드·세션 토큰·신분증 사본은 보내지 마세요.

앱 밖 요청은 Google 재인증 기반 웹 탈퇴·진행 상태 조회 방식으로 구현하기로 결정했습니다. 본인 확인은 Google의 계정 인증과 기존 회원의 연결 정보를 대조하며, 이메일 발신 주소만으로 소유자를 판단하지 않습니다.

처리 결과는 인증된 웹 조회 화면으로 안내하는 방향이며 개인 이메일 주소를 공개하는 회신 방식은 사용하지 않습니다. 현재 웹 기능은 아직 구현·검증되지 않아 이 페이지에서 탈퇴를 실행하거나 결과를 조회할 수 없습니다. 사용할 수 있는 탈퇴 기능은 위의 앱 내 절차입니다.
