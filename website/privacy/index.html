개인정보 안내

LinkFileBox의 개인정보 처리와 이용자 요청을 안내합니다. 최신 안내의 기준은 이 페이지입니다.

LinkFileBox는 개인 개발자가 운영합니다.

제1조 (처리하는 정보와 목적)

  • 인증과 회원 승인: Google 로그인으로 전달되는 계정 식별정보·이메일과 회원 승인 상태를 계정 인증·접근 제어에 이용합니다. Google 계정 비밀번호를 앱에 입력받지 않습니다.
  • 개인 보관함: 사용자가 저장한 URL·제목·메모·분류와 확보한 메타정보를 저장·검색·분류에 이용합니다.
  • 직접 선택한 첨부: 항목당 이미지 한 장과 OCR 인식 결과를 저장·검색에 이용합니다. OCR은 기기에서 실행되지만 선택한 이미지와 결과는 서버에 업로드됩니다.
  • 기기 내 처리: 로그인 세션, 대기 중인 전송 요청과 임시 작성 내용, 보관함 캐시를 저장해 재접속과 재전송에 이용합니다.
  • 문의·운영·삭제 처리: 문의 이메일과 요청 내용, API 요청·속도 제한 기록, 본인 확인용 임시 요청과 삭제 진행·재처리 기록을 문의 응대·접근 제어·안전한 삭제에 이용합니다.

링크·메모·이미지에 불필요한 민감정보나 다른 사람의 개인정보를 포함하지 마세요. SNS의 좋아요나 비공개 계정 전체 자료를 자동 수집하는 기능은 없습니다.

제2조 (서비스 구성과 외부 처리)

  • Google: 로그인 인증, 선택한 이미지의 기기 내 ML Kit OCR.
  • 자체 운영 Supabase: 계정·DB·비공개 이미지 저장소와 API. 현재 AI Testbed 제공 NCP 서버를 사용합니다.
  • Cloudflare: 도메인·API 앞단의 네트워크 처리와 문의 메일 전달.
  • Gmail: 전달된 문의 메일 수신·확인.
  • GitHub Actions: 운영 자동화와 암호화 백업 아티팩트 보관.

각 서비스의 위탁 관계·처리 국가·지역, 국외 이전 해당 여부·근거와 필요한 고지·동의는 확정 전입니다.

제3조 (보관과 삭제)

항목 삭제나 계정 탈퇴로 회원 자료 삭제를 요청할 수 있습니다. 운영 자료 정리는 72시간 이내 목표, 운영 백업은 30일 순환 목표입니다. 모든 사본의 즉시 삭제나 최대 보관 기간·완료 시각을 보장하지 않습니다.

서버 백업 도구는 서버 밖 독립 복원 검증이 확인된 경우에만 최근 7개·30일 기준으로 자동 정리합니다. 현재 유효한 복원 검증 증거가 없어 기존 서버 스냅샷을 모두 보존합니다. 스냅샷 개수는 보관 일수와 다르며 파일 생성·암호화만으로 복원 검증이 되지는 않습니다.

복원 검증 후에도 대체 검증 복구본이 없으면 마지막 검증 복구본과 필요한 삭제 원장은 순환 기준을 넘겨 예외 보존하고 운영 경고로 관리합니다. 백업으로 복원할 때도 삭제 요청을 다시 적용해야 합니다. 별도 복사본·외부 백업·삭제 원장의 최종 보관·파기 기준은 확정 전입니다.

삭제 작업·감사 기록은 활성 보관함 자료와 구분됩니다. 다음은 정리 대상이 되는 조건이며 삭제 완료 기한이 아닙니다.

  • API 요청 기록: 7일 경과. 요청 빈도 제한 기록: 1일 경과.
  • 완료된 첨부 정리 기록: 완료 후 30일 경과.
  • 항목 삭제 표식·완료된 계정 삭제 작업: 30일 경과와 삭제 기록 내보내기 확인. 확인되지 않으면 더 오래 보관될 수 있습니다.
  • 삭제 원장: 계정·항목·요청 식별자와 처리 시각 등을 기록하며, 30일 경과·내보내기 확인·연결된 삭제 표식과 작업 정리가 필요합니다. 진행 중인 계정 삭제 작업은 기간만으로 삭제하지 않습니다.

문의 메일과 운영 로그의 실제 수집 범위·최종 보관·파기 기준도 확정 전입니다.

제4조 (요청 방법)

앱에서 항목을 수정·삭제하거나 계정 탈퇴를 요청할 수 있습니다. 앱을 이용하기 어려우면 웹에서 Google 재인증 후 탈퇴를 요청하고 진행 상태를 조회하세요.

열람·정정 등 다른 요청은 문의 주소로 보내주세요. 본인 확인이 필요하며 이메일 발신 주소만으로 계정을 자동 삭제하지 않습니다. 비밀번호·인증 코드·토큰·신분증 사본은 보내지 마세요.

웹 진행 조회에는 Google 계정 식별자의 해시값과 삭제 작업 연결을 사용하며 웹 재인증 토큰은 서버에 저장하지 않습니다. 완료 후 30일이 지나면 조회 연결은 정리 대상이 되고, 진행 중인 작업의 연결은 완료될 때까지 유지합니다. 조회 기록을 찾지 못했다는 응답은 삭제 완료를 뜻하지 않습니다.
